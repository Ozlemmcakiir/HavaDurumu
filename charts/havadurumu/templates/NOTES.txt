Gökyüzü ({{ .Chart.Name }}) yüklendi.

  Release   : {{ .Release.Name }}
  Chart     : {{ .Chart.Name }}-{{ .Chart.Version }}
  Namespace : {{ .Release.Namespace }}
  Pod sayısı: {{ .Values.replicaCount }}
  İmaj      : {{ .Values.image.repository }}:{{ .Values.image.tag }}
  Service   : {{ .Values.service.type }} {{ include "havadurumu.name" . }}:{{ .Values.service.port }}
{{- if .Values.ingress.enabled }}
  Ingress   : {{ .Values.ingress.host }}  (nginx)
{{- end }}

Demo URL (ücretsiz host, domain / A kaydı yok):

  1. Ingress controller hazır olsun:
       minikube addons enable ingress
  2. nginx'i laptop'a bağla (pencere açık kalsın):
       .\scripts\open-demo.ps1
  3. Tarayıcı (laptop):
       http://{{ .Values.ingress.host }}:8080
  4. Telefon (aynı Wi-Fi, mobil veri kapalı):
       http://<laptop-Wi-Fi-IP>:8080

Akış: tarayıcı → nginx Ingress → Service → Flet pod.

Ölçeklemek için values.yaml içinde replicaCount'u değiştirip tekrar:

  helm upgrade --install {{ .Release.Name }} charts/havadurumu

Durumu görmek:

  helm list -A
  kubectl get pods,svc,ingress -l app={{ include "havadurumu.name" . }}
